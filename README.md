Repository for https://www.stardustmotion.org/ website

### to build

Install [Typescript](https://www.typescriptlang.org/)/[Less](https://lesscss.org/), generate js/css, then test

```
>>> npm install typescript --save-dev
>>> npm install less --save-dev
>>> ./build_js.sh
>>> ./build_css.sh
// Run localhost i.e
>> npx http-server -c 5
```
